Supported files
Supported files and limits
  • .env and .env.*
  • Docker Compose
  • GitHub Actions
  • Kubernetes workloads

        
Limits
What it does not do
  • It does not read secret stores.
  • It does not decrypt values.
  • It does not watch running processes.
  • It does not guess vendor behavior.
